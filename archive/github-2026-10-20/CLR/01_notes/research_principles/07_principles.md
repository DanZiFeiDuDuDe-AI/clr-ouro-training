# CLR Research Principles

1. **Adapter separation** — Never merge. Modular > monolithic
2. **High-emotion data restriction** — Bluemoon < 10%
3. **Persona ≠ knowledge** — Epoch=1, subtle consistency is correct
4. **Novelty = S_t utilization** — Need causal evidence, not emotion embeddings
5. **Evaluation > modules** — Build CLR-Bench before adding complexity
