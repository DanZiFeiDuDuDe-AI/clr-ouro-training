## 文件追溯

`manifests/files.jsonl` 每行对应一个归档路径，包含来源、文件大小、原始 SHA-256、发布 SHA-256，以及 `git` / `release` 存储位置。`manifests/redactions.json` 记录哪些发布副本移除了凭据，但不记录凭据原文。

同一内容出现在不同来源目录时，路径记录会分别保留，Release 则按内容哈希去重。原 GitHub 基线 commit 保存在 `manifests/archive_summary.json`。
