## 发布副本与原文件的区别

原始本地研究目录未被移动或修改。只有发布副本中的硬编码密码、访问令牌等被移除；Python 中可直接识别的密码字面量改为环境变量读取，其余文本凭据改为脱敏占位符。未将凭据原文写入脱敏报告。

模型词表、merges 和 tokenizer 配置保持原始字节，不对其中偶然出现的普通词汇、数字 token 做替换，避免破坏模型的 token ID 契约。它们与带账号、主机和密码字段的认证配置分开处理。

`source_sha256` 表示来源文件，`sha256` 表示发布副本；两者不同时，应结合 `redacted` 与 `manifests/redactions.json` 解释。历史报告、数值和旧哈希清单保持证据原貌，不补写伪造的旧 commit 或实验通过声明。
