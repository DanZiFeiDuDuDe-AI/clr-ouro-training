## MusicUnderstand 项目

- **路径:** H:\musicunderstand
- **类型:** 音乐情绪理解模型 (valence/arousal)
- **架构:** Mel频谱 → CNN (64→128→256) → 双向LSTM (256, 2层) → 逐帧 valence + arousal
- **数据集:** DEAM (1800+ 首歌曲，逐秒情绪标注)
- **训练:** 已完成，best_model.pth (12MB)
- **推理测试:** 用张军 - 霓裳羽衣.wav 测试成功，输出有意义的情绪曲线
- **特点:** 无CUDA（CPU运行），模型对传统音乐（昆曲）的结构变化有合理的捕捉
- **后续可能:** README 中提到阶段二加 LLM Interpreter 把情绪曲线翻译成自然语言
