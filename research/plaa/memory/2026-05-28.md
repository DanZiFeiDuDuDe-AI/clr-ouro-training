## 下午-晚上 · Phase 3 Stage B 梯度调试

**目标：** 将 Emotion Cross-Attention 注入 Qwen3-4B 层 16-28，验证梯度闭环。

### 架构设计

```
Qwen Layer (original)
  ├─ Self-Attention (original)
  ├─ Residual
  ├─ Emotion Cross-Attention  ← K,V = e_mem, gate = tanh(α)
  ├─ Gated Residual Merge     ← hs + tanh(gate) * ca_out
  └─ MLP (original)
```

### 调试过程（7 轮迭代中的关键发现）

| # | 问题 | 根因 | 修复 |
|:-:|------|------|------|
| 1 | flash_attention batch flatten | FA2 把 [B,T,D] 展平成 [B*T,D]，e_mem batch 对不上 | 切到 SDPA |
| 2 | requires_grad 崩溃 | 4-bit int 参数不能设 requires_grad=True | 加 `is_floating_point` 检查 |
| 3 | TrainerCallback 缺方法 | GCC 缺 on_init_end | 继承 `TrainerCallback` |
| 4 | Device mismatch | nn.Linear 默认 CPU，模型在 CUDA | `.cuda()` |
| 5 | **Loss diff = 0** | _e 用动态 attribute，PEFT wrapper 不追踪 | 改用 `register_buffer` |
| 6 | bf16/fp32 dtype NaN | gate 默认 float32，模型 bf16 | 加 `dtype=torch.bfloat16` |
| 7 | PEFT 初始化顺序 | 先 PEFT wrap 再 inject → PEFT 的 module tree 不包含 inj | **先 inject 再 PEFT wrap** |

### 根因总结

**最关键的发现：** `PeftModel.from_pretrained` 的 wrapper hierarchy 极其复杂：

```
PeftModel
  └─ LoraModel (base_model)
     └─ model (Qwen3ForCausalLM)
        └─ model (Qwen3Model)
           └─ layers[16..28]
```

注入的顺序必须是：**先 inject → 再 PEFT wrap**，否则 InjLayer 不在 PEFT 的 module tree 中。

**第二个关键发现：** 用 `register_buffer("_e", None)` 而不是 `self._e = None`。动态 attribute 会被 PEFT/Accelerate 的一些 internal path 忽略，造成静默断图。

## 晚上 · Stage C Behavior Probe

**目标：** 验证 e_mem 是否实际改变模型输出。

**方法：** 同一 prompt "What do you think about music?"，不同 e_mem scale [-3, -1, 0, +1, +3]。

**结果：**

| e_mem | Output (truncated) | 特征 |
|:-----:|:-------------------|:------|
| -3.0 | "...the band The Beatle" | 具体引用，直接 |
| -1.0 | "What's your favorite genre?" | 单问题，直接 |
| +0.0 | "Do you like listening to it?" | 中性 |
| +1.0 | "Do you listen to it? What do you like?" | 探索性，多问题 |
| +3.0 | "...the idea of a person le" | 哲学方向 |

**结论：** e_mem 确实调制了模型输出风格。负值→更具体/直接，正值→更发散/哲学。
