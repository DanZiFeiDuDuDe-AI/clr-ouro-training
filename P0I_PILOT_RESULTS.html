8. 推测与结论

8.1 Teacher Imitation - Candidate Ranking 错位

数据清楚地显示了一个反直觉的系统性模式：蒸馏过程不断提高 teacher logit fidelity（cosine 从 0.749 升至 0.995）， 但 candidate ranking 系统性恶化（accuracy 从 15/150 降至 0/150，mean rank 从 ~4 恶化到 ~10）。

可能的解释：

  • Retention/Attention 功能差异本质：Retention 的衰减递归在数学上不等价于 softmax attention。即使 logit 分布相似，隐含的 information routing 路径不同。当 teacher imitation 压迫 retention 的隐式状态表示向 attention 的 KV cache 靠拢时，它可能破坏 retention 原始（但 differentiable）的跨 token 信息整合方式。
  • Post-norm 过拟合 teacher：norm1800 → H2-v2 的路径显示，post-norm 逐渐学习补偿 retention 与 attention 之间的表示差异，使表面 logit 趋同，但内部表示的 geometric structure 可能已经偏离了能正确 rank candidate 的方向。
  • Candidate scoring 是 non-linear selection：argmax/mean-log-prob 对 logit 空间的微小差异极度敏感。KL divergence 对整体分布施加压力，但 candidate ranking 取决于正确候选 vs 最佳错误候选的 margin——这是一个局部、非线性的指标，KL 无法直接优化。

8.3 核心结论

  1. H2-v2 判定为 negative result，正式关闭。rank_loss 与 candidate-scoring scoring 函数完全一致，排除了 implementation mismatch。1500 步训练后 teacher fidelity 极高（cos=0.995）但 candidate accuracy 仍为 0。
  2. Teacher imitation objective 是导致 candidate ranking 失败的直接原因。这不是 capacity 不足（393K LoRA params），而是 objective 方向错误：KL 压迫 retention 的内部表示向 attention 靠拢，破坏了 candidate ranking 所需的局部 margin 结构。
  3. 0I pilot 改用 task objective 是正确的方向转折。不依赖 teacher cache、不用 KL、不用 block loss——直接优化 candidate CE。M1 两组 600 步训练 loss 正常收敛。
  4. 0I pilot 的 N1800 两组仍在进行中，暂时无法给出 persist vs reset 的最终比较。

9. 思路方向建议

9.1 短期（0I pilot 完成后）

  • 完成 4 组 0I pilot 评估：N1800-reset 和 N1800-persist 完成后，在同一 P0H5 N=150 上统一评估，比较 Acc(persist) - Acc(reset)。
  • 如果 persist > reset：说明 cross-turn retention state persistence 有 causal task effect。此时扩多 seed 验证，并进入 0J 做更细致的 state lifetime 消融。
  • 如果 persist ≈ reset：需要检查 state 是否真持久、真变化、真被读取。可能需要更长的训练（600 步可能不够让模型学会利用 persistent state）。
  • 如果 persist < reset：persistent state 可能引入 interference / stale state 问题。保留结果，分析 state norm / delta / cosine。

9.2 中期方向

  • 放弃 teacher imitation 路线：0H/H2 的全部数据证明这条路在 candidate ranking 上是 dead end。task objective（candidate CE / hinge）是唯一能直接优化 candidate margin 的方式。
  • 增加 training scale：600 步可能不足以让 post-norm 适配 retention 的 differentiability。考虑 1500-3000 步 task training。
  • 考虑 unfreeze gamma：当前 gamma 冻结。如果 retention 的 decay rate 可以适配 task，cross-turn state 的 information lifetime 可能更合理。但 0H 证明 gamma-only 几乎无修复能力，所以只在 task objective 下尝试。
  • 探索 partial unfreeze：除了 post-norm，考虑 unfreeze Q/K/V/O 的 LoRA（低 rank），但用 task objective 而非 KL。这比 H2-v2 的关键区别是 objective：task CE vs teacher KL。

9.3 长期方向

  • Retention-specific task architecture：如果 persist 有 positive effect，考虑设计 retention-native 的 multi-turn reasoning 架构，而非在 attention model 上做 surgical replacement。
  • State routing / gating：让模型学习何时使用 persistent state vs 何时 reset。可以加一个 gate（类似 LSTM 的 forget gate）在 turn 边界。
  • Multi-seed statistical validation：seed 42 只是 pilot。如果效应存在，需要 5+ seeds 做 bootstrap CI。
